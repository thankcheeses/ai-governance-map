## 🛠️ Product Walkthrough

### 1. Execute Technical Assessments
Don't just check a box. Use the **Indicator Identity Card** section to define the math behind your compliance. 
* **Math-Ready**: Define expressions (e.g., `Unauthorized_Attempts / Total_Calls`).
* **Standardized SLOs**: Set 2026-compliant Service Level Objectives.
* **Change Management**: Toggle the **"Significant System Change"** flag to trigger immediate re-validation when your agentic architecture shifts.

### 2. Visualize Posture Gap
The **Posture Radar** aggregates your CMMI scores into a domain-level view. 
* Instantly identify technical risk debt in areas like **AIS** (Application Security) or **DSP** (Data Security).
* Powered by high-performance SVG rendering.



### 3. "Test Once, Comply Many"
The **Overlap Matrix** allows you to discover efficiencies across 25 global frameworks.
* Click a matrix cell to filter controls that satisfy both **ISO 42001** and the **EU AI Act** simultaneously.
* Reduce audit fatigue through automated framework cross-walking.

```bash
