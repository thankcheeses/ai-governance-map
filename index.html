NHID-Clinical in the 5-Layer Trust Stack for B2B Healthcare Voice
LayerScope
Layer 0NPI Registry — no delegation proof, no call-time authorization
Layer 1STIR/SHAKEN — carrier attestation (A/B/C levels), verifies phone number origin only
Layer 2 ★NHID-Clinical v1.3 — Behavioral Baseline (disclosure, no mimicry, handoff, audit log)
Layer 3NHID-Auth v2 — Cryptographic authorization layer: Ed25519 delegation chain + DPoP call-nonce binding (reference implementation, CC BY 4.0)
Layer 4FHIR AuditEvent R4 (HL7 base spec v4.0.1) — healthcare-native structured logging; no named Implementation Guide (e.g. IHE BALP) conformance claimed
Layer 5OpenTelemetry spans → SIEM / enterprise observability pipeline

★ NHID-Clinical v1.3 is the behavioral baseline at Layer 2. Cryptographic NPI delegation verification lives in NHID-Auth v2 at Layer 3 — a separate, optional authorization layer, not folded into Layer 2 conformance.
